# AI-Powered Employee Salary Predictor

A Machine Learning web application built using Streamlit and Scikit-learn that predicts employee salaries based on experience, department, education, age, gender, and city.

## Features
- Salary Prediction
- Data Visualization Dashboard
- Heatmaps and Analytics
- Interactive UI

## Tech Stack
- Python
- Streamlit
- Scikit-learn
- Pandas
- Matplotlib
- Seaborn
